<h1 align="center">Fling Launcher</h1>

<p align="center">
  A desktop launcher for Hello Neighbor builds, made for speedrunners.<br />
  Manage every build in one place, patch in community multiplayer mods, install & run tools, and check the leaderboards.
</p>
