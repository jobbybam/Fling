UUU

Unreal Engine Unlocker is a tool that injects a dll into an Unreal Engine 4 game that natively unlocks the developer console, activate the console in-game using the tilde key (`).

FModel

FModel is an Unreal Engine archive explorer — it opens a game's packaged .pak/.utoc files directly and lets you browse and export its assets (textures, meshes, sounds, and more) without touching the running game.
