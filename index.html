UUU

Unreal Engine Unlocker is a tool that injects a dll into an Unreal Engine 4 game that natively unlocks the developer console, activate the console in-game using the tilde key (`).

Helpful Commands

UModel

UModel (Unreal Model Viewer) is an Unreal Engine asset viewer and extractor. It opens a game's packaged .pak files directly, letting you browse and export its assets (textures, meshes, animations, sounds, and more) without touching the running game.

LiveSplit

LiveSplit is the standard split timer for speedrunning. It tracks your splits, personal best and gold segments, and supports global hotkeys so you can split while the game has focus. Install it here in one click and launch it from the launcher.

Leaderboard

Pick a full game to see its top 50 runs, live from speedrun.com.
